# Flow Core (Plan A) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `aistudio flow credits`, `aistudio flow video` and `aistudio flow image`. They drive Google Flow's agent in a minimized Chrome, spend credits only under an explicit `--max-credits` budget, and save the results without ever losing a paid file.

**Architecture:** This plan follows the existing layers:
- `_flow/wire.py` and `_flow/rows.py` decode Flow's `batchexecute` responses and the agent's quote text;
- `_flow/models.py` holds the model table and the pure `decide()` function;
- `_flow/page.py` drives the page through the `Ui` protocol;
- `_flow/download.py` fetches signed links;
- `_app/flow.py` holds the use cases;
- `cli/flow_cmd.py` is the command group.

The never-lose writer moves to `_media/save.py` so AI Studio and Flow share it.

**Tech Stack:** Python 3.10+, click, httpx, Playwright, pytest + pytest-asyncio, respx, ruff (line length 100).

**Spec:** `docs/superpowers/specs/2026-10-07-flow-generation-design.md`. The evidence is in `docs/wire/findings.md`, section "Google Flow (flow.google.com) discovery".

**Scope of this plan:** spec §3 for `credits`, `video` and `image`; §3.1 spending; §3.2 results for those commands; §4–§8 for them. **Plan B** comes after this ships and its free discovery is recorded. It covers `projects`, `media`, `download`, `extend`, `scene`, `character create/list`, `--start-frame`, `--end-frame`, `--ingredient` and `--character`.

## Global Constraints

- No feature may need a Gemini API key. Flow runs on the saved Google session in a minimized Chrome (`window="minimized"`), and `--visible` shows it.
- Credits are spent only when `decide()` returns APPROVE, with an explicit `--max-credits` and exactly one radio named "Approve". "Always approve" is never pressed.
- Without `--max-credits`, nothing is spent: the result is `status: "quoted"`, exit 0.
- Writes go only to the "aistudio" project (stored id) or the `--project` one. Other projects are never written to.
- Flow's tune defaults are restored in `finally`. If restoring fails, the result gets a warning naming the setting.
- A paid result is never lost: files go through `_media/save.write_file`, and every failure after Approve names the media ids.
- No tokens, cookies, XSRF values or signed-link signatures appear in logs, fixtures or output.
- Errors: new codes `OVER_BUDGET`, `PLAN_MISMATCH` and `AGENT_REPLY` (exit 1). A job timeout is `status: "timeout"` with exit 2.
- ruff is clean, and the whole suite is green after every task.
- Live paid tests are marked `live_slow` and run only with the user's OK.

```python
# src/aistudio/_flow/wire.py
"""Google Flow's batchexecute framing (docs/wire/findings.md, "Google Flow").

A response is ``)]}'``, a blank line, then length lines each followed by a JSON array. An entry
``["wrb.fr", rpcid, "<json>", …]`` carries one RPC's payload as a JSON string.
"""

from __future__ import annotations

import json
from typing import Any


def decode_batch(text: str) -> dict[str, Any]:
    out: dict[str, Any] = {}
    for line in text.splitlines():
        line = line.strip()
        if not line.startswith("[["):
            continue
        try:
            entries = json.loads(line)
        except ValueError:
            continue
        for entry in entries if isinstance(entries, list) else []:
            if (isinstance(entry, list) and len(entry) > 2 and entry[0] == "wrb.fr"
                    and isinstance(entry[2], str)):
                try:
                    out[str(entry[1])] = json.loads(entry[2])
                except ValueError:
                    continue
    return out
```

```python
# src/aistudio/_flow/rows.py
"""Decode Flow media records, credits, and the agent's quote and plan (findings "Google Flow")."""

from __future__ import annotations

import re
from dataclasses import dataclass
from typing import Any

from aistudio._rpc.wire import opt_index

_VIDEO = "https://flow-content.google/video/"
_IMAGE = "https://flow-content.google/image/"
_QUOTE = re.compile(r"kick off (?:this|these) ([\d,]+) (video|image) generations?, costing "
                    r"([\d,]+) credits?", re.I)
_SECONDS = re.compile(r"(\d+)-second", re.I)
_MODEL = re.compile(r"\busing ((?:Veo|Omni|Nano Banana)[\w .\-]*?)(?=[.,;!?]|\s+(?:with|in|at|"
                    r"and)\b|$)", re.I)


@dataclass(frozen=True)
class FlowMedia:
    media_id: str
    project_id: str | None
    prompt: str | None
    model_key: str | None
    status: int | None  # 2 running, 3 done
    seconds: int | None
    size: int | None
    video_url: str | None
    image_url: str | None


@dataclass(frozen=True)
class Quote:
    count: int
    kind: str  # "video" | "image"
    credits: int


@dataclass(frozen=True)
class Plan:
    model: str | None  # as the agent names it, e.g. "Veo 3.1 - Lite"
    seconds: int | None


def media_records(method: str, payload: Any) -> list[FlowMedia]:
    """``jwpduf``: ``[None, credits, [record, …]]``; ``as29s``/``bOKtO``: one record (or a list)."""
    if method == "jwpduf":
        rows = opt_index(payload, 2)
    elif method in ("as29s", "bOKtO"):
        rows = [payload] if isinstance(opt_index(payload, 0), str) else (
            opt_index(payload, 0) if isinstance(opt_index(payload, 0), list) else [])
    else:
        return []
    out = []
    for row in rows if isinstance(rows, list) else []:
        media = _record(row)
        if media is not None:
            out.append(media)
    return out


def credits_left(payload: Any) -> int | None:
    value = opt_index(payload, 1)
    return value if isinstance(value, int) and not isinstance(value, bool) else None


def parse_quote(text: str) -> Quote | None:
    match = _QUOTE.search(text)
    if match is None:
        return None
    return Quote(count=int(match.group(1).replace(",", "")), kind=match.group(2).lower(),
                 credits=int(match.group(3).replace(",", "")))


def parse_plan(text: str) -> Plan:
    model = _MODEL.search(text)
    seconds = _SECONDS.search(text)
    return Plan(model=model.group(1).strip() if model else None,
                seconds=int(seconds.group(1)) if seconds else None)


def _record(row: Any) -> FlowMedia | None:
    media_id = opt_index(row, 0)
    if not isinstance(media_id, str) or not media_id:
        return None
    details = opt_index(row, 5)
    links = list(_strings(row))
    status = opt_index(details, 8, 0)
    seconds = opt_index(row, 7, 1, 2, 0)
    size = opt_index(details, 13)
    return FlowMedia(
        media_id=media_id,
        project_id=opt_index(row, 1) if isinstance(opt_index(row, 1), str) else None,
        prompt=opt_index(details, 1) if isinstance(opt_index(details, 1), str) else None,
        model_key=_str(opt_index(details, 6, 1, 0, 0)),
        status=status if isinstance(status, int) else None,
        seconds=seconds if isinstance(seconds, int) else None,
        size=size if isinstance(size, int) else None,
        video_url=next((s for s in links if s.startswith(_VIDEO)), None),
        image_url=next((s for s in links if s.startswith(_IMAGE)), None),
    )


def _str(value: Any) -> str | None:
    return value if isinstance(value, str) and value else None


def _strings(node: Any):
    if isinstance(node, str):
        yield node
    elif isinstance(node, list):
        for child in node:
            yield from _strings(child)
```

```python
# src/aistudio/_flow/models.py
"""Flow's models and options, the instruction sent to its agent, and the spend decision (spec §3)."""

from __future__ import annotations

import enum
from dataclasses import dataclass

from aistudio._flow.rows import Plan, Quote
from aistudio.exceptions import ValidationError

ASPECTS = {"video": ("16:9", "9:16"), "image": ("16:9", "4:3", "1:1", "3:4", "9:16")}
COUNTS = (1, 2, 3, 4)


@dataclass(frozen=True)
class FlowModel:
    id: str
    label: str  # as Flow's model picker shows it
    kind: str  # "video" | "image"
    durations: tuple[int, ...] = ()


MODELS = (
    FlowModel("omni-1.1-flash", "Omni 1.1 Flash", "video", (4, 6, 8, 10)),
    FlowModel("veo-3.1-lite", "Veo 3.1 - Lite", "video", (4, 6, 8)),
    FlowModel("veo-3.1-fast", "Veo 3.1 - Fast", "video", (4, 6, 8)),
    FlowModel("veo-3.1-quality", "Veo 3.1 - Quality", "video", (8,)),
    FlowModel("nano-banana-2.1", "Nano Banana 2.1", "image"),
    FlowModel("nano-banana-pro", "Nano Banana Pro", "image"),
)


def find_model(model_id: str, kind: str) -> FlowModel:
    wanted = model_id.strip().lower()
    for model in MODELS:
        if model.id == wanted:
            if model.kind != kind:
                raise ValidationError(f"{model.id} is a {model.kind} model",
                                      hint=f'use "aistudio flow {model.kind}"')
            return model
    ids = ", ".join(m.id for m in MODELS if m.kind == kind)
    raise ValidationError(f"Flow has no {kind} model {model_id!r}", hint=f"choose one of: {ids}")


def check_options(kind: str, model: FlowModel | None, aspect: str | None, count: int | None,
                  duration: int | None) -> None:
    if aspect is not None and aspect not in ASPECTS[kind]:
        raise ValidationError(f"Flow {kind}s come in {', '.join(ASPECTS[kind])}, not {aspect}")
    if count is not None and count not in COUNTS:
        raise ValidationError("--count must be 1 to 4")
    if duration is not None:
        if kind == "image":
            raise ValidationError("images have no --duration")
        allowed = model.durations if model else (4, 6, 8, 10)
        if duration not in allowed:
            name = model.id if model else "Flow"
            raise ValidationError(f"{name} makes {', '.join(map(str, allowed))}-second videos, "
                                  f"not {duration}")


def instruction(kind: str, prompt: str, *, count: int, model_label: str | None,
                seconds: int | None, aspect: str | None) -> str:
    noun = kind if count == 1 else f"{kind}s"
    length = f"{seconds}-second " if seconds else ""
    model = f" with {model_label}" if model_label else ""
    shape = f" in {aspect}" if aspect else ""
    return (f"Generate exactly {count} {length}{noun}{model}{shape}. Do not make a storyboard "
            f"or any other {kind}s. Prompt: {prompt}")


class Decision(enum.Enum):
    QUOTE_ONLY = "quote_only"
    APPROVE = "approve"
    REJECT_OVER_BUDGET = "reject_over_budget"
    REJECT_MISMATCH = "reject_mismatch"


@dataclass(frozen=True)
class Expect:
    kind: str
    count: int
    model: str | None  # a label; None when the person did not ask for one
    seconds: int | None


def decide(quote: Quote, plan: Plan, expect: Expect,
           max_credits: int | None) -> tuple[Decision, list[str]]:
    """Spend only with a budget, a matching plan and a quote within the budget (spec §3.1)."""
    wrong: list[str] = []
    if quote.kind != expect.kind:
        wrong.append(f"kind: expected {expect.kind}, quoted {quote.kind}")
    if quote.count != expect.count:
        wrong.append(f"count: expected {expect.count}, quoted {quote.count}")
    if expect.model is not None and _norm(plan.model) != _norm(expect.model):
        wrong.append(f"model: expected {expect.model!r}, planned {plan.model!r}")
    if expect.seconds is not None and plan.seconds != expect.seconds:
        planned = f"{plan.seconds} s" if plan.seconds is not None else "no length"
        wrong.append(f"length: expected {expect.seconds} s, planned {planned}")
    if max_credits is None:
        return Decision.QUOTE_ONLY, wrong
    if wrong:
        return Decision.REJECT_MISMATCH, wrong
    if quote.credits > max_credits:
        return Decision.REJECT_OVER_BUDGET, wrong
    return Decision.APPROVE, wrong


def _norm(label: str | None) -> str:
    return "".join(ch for ch in (label or "").lower() if ch.isalnum())
```

```python
"""Download Flow media from its signed CDN links; no cookies are sent (findings "Google Flow")."""

from __future__ import annotations

from urllib.parse import urlparse

import httpx

from aistudio.exceptions import NetworkError, ServerError, ValidationError

ALLOWED_HOST = "flow-content.google"


async def download_signed(url: str, *, client: httpx.AsyncClient | None = None) -> bytes:
    parsed = urlparse(url)
    if parsed.scheme != "https" or parsed.hostname != ALLOWED_HOST:
        raise ValidationError(f"refusing to download from {parsed.scheme}://{parsed.hostname}")
    owned = client is None
    http = client or httpx.AsyncClient(timeout=120.0, follow_redirects=False)
    try:
        response = await http.get(url)
    except httpx.TransportError as exc:
        raise NetworkError(f"{type(exc).__name__}: {exc}") from exc
    finally:
        if owned:
            await http.aclose()
    if 200 <= response.status_code < 300:
        return response.content
    if response.status_code in (401, 403):
        raise ServerError("the Flow download link expired or was refused",
                          hint="open the project in Flow and download it there")
    raise ServerError(f"Flow download failed (HTTP {response.status_code})")
```

```python
"""Drive Google Flow's project page and agent (docs/wire/findings.md, "Google Flow").

The project page is agent-only. The prompt is a ProseMirror editor (keyboard typing only), the
tune panel holds the defaults, and permission questions are radios inside

from collections.abc import Callable
from dataclasses import dataclass

                "image": "Image generation default model"}

class Defaults:

    count: int

    media: list[FlowMedia]

def _aspect_name(aspect: str) -> re.Pattern[str]:
    return re.compile(rf"(^|\s){re.escape(aspect)}$")


def _count_name(count: int) -> re.Pattern[str]:
    return re.compile(rf"^x{count}$")


def _group(kind: str, aspect: str | None = None) -> int:
    """Index of a tune control: shared names (16:9, 9:16, xN) appear once per group."""
    if aspect is not None and aspect not in ("16:9", "9:16"):
        return 0  # only images offer 4:3, 1:1 and 3:4
    return GROUP[kind]


def _label(text: str) -> str:
    """'🍌 Nano Banana 2.1 arrow_drop_down' -> 'Nano Banana 2.1'."""
    words = [w for w in text.split() if w != "arrow_drop_down" and any(c.isalnum() for c in w)]
    return " ".join(words)


class FlowPage:
    def __init__(self, ui: Ui, *, now: Callable[[], float] = time.monotonic,
                 poll_s: float = 1.0) -> None:
        self._ui = ui
        self._now = now
        self._poll_s = poll_s

    async def open_project(self, project_id: str) -> None:
        await self._ui.goto(PROJECT_URL.format(id=project_id))
        try:
            await self._ui.wait_for(PROMPT_EDITOR, timeout_s=30.0)
        except BrowserError as exc:
            raise NotFoundError(f"Flow project {project_id} did not open",
                                hint="check the id, or leave out --project") from exc

    async def create_project(self, title: str) -> str:
        await self._ui.goto(HOME_URL)
        await self._ui.activate("button", NEW_PROJECT)
        project_id = None
        for _ in range(60):
            match = PROJECT_ID.search(self._ui.current_url())
            if match:
                project_id = match.group(1)
                break
            await self._ui.pause(500)
        if project_id is None:
            raise BrowserError("Flow did not open the new project",
                               hint="re-run; if it persists, the Flow UI changed")
        await self._ui.fill("textbox", TITLE, title)
        await self._ui.press("textbox", TITLE, "Enter")
        return project_id

    async def new_session(self) -> None:
        await self._ui.activate("button", NEW_SESSION, exact=True)
        await self._ui.pause(1000)

    async def read_defaults(self, kind: str) -> Defaults:
        await self._ui.activate("button", TUNE, exact=True)
        await self._ui.pause(1200)
        model = _label(await self._ui.inner_text("button", MODEL_BUTTON[kind], exact=True))
        aspect = await self._checked_one(kind, ASPECTS[kind], _aspect_name, aspect=True)
        count = await self._checked_one(kind, (1, 2, 3, 4), _count_name, aspect=False)
        await self._close_tune()
        if not model or aspect is None or count is None:
            raise BrowserError(f"could not read Flow's {kind} defaults",
                               hint="re-run; if it persists, the Flow UI changed")
        return Defaults(model, str(aspect), int(count))

    async def apply_defaults(self, kind: str, wanted: Defaults) -> None:
        await self._ui.activate("button", TUNE, exact=True)
        await self._ui.pause(1200)
        current = _label(await self._ui.inner_text("button", MODEL_BUTTON[kind], exact=True))
        if current != wanted.model:
            await self._ui.activate("button", MODEL_BUTTON[kind], exact=True)
            await self._ui.pause(1000)
            await self._ui.activate(MODEL_OPTION_ROLE, re.compile(re.escape(wanted.model)))
            await self._ui.pause(1000)
        await self._ui.activate(TUNE_ROLE, _aspect_name(wanted.aspect),
                                nth=_group(kind, wanted.aspect))
        await self._ui.activate(TUNE_ROLE, _count_name(wanted.count), nth=_group(kind))
        await self._ui.pause(800)
        await self._close_tune()
        if await self.read_defaults(kind) != wanted:
            raise BrowserError(f"Flow's {kind} settings did not take effect",
                               hint="re-run; if it persists, the Flow UI changed")

    async def submit(self, text: str) -> None:
        await self._ui.type_text(PROMPT_EDITOR, text)
        await self._ui.key("Enter")

    async def wait_for_quote(self, *, timeout_s: float = 90.0) -> AgentTurn:
        deadline = self._now() + timeout_s
        text = ""
        while self._now() < deadline:
            text = await self._ui.text_of(AGENT_MESSAGE)
            quote = parse_quote(text) if text else None
            if quote is not None:
                return AgentTurn(text, quote)
            await self._ui.pause(int(self._poll_s * 1000))
        return AgentTurn(text, None)

    async def reject(self) -> None:
        await self._ui.activate("radio", "Reject", exact=True)
        await self._ui.pause(1000)

    async def approve_and_follow(self, *, count: int, timeout_s: float) -> FlowOutcome:
        if len(await self._ui.labels("radio", re.compile(r"^Approve$"))) != 1:
            raise BrowserError("could not find exactly one Approve option; nothing was spent",
                               hint="re-run; if it persists, the Flow UI changed")
        async with self._ui.responses(marker=FLOW_RPC) as log:
            await self._ui.activate("radio", "Approve", exact=True)
            return await self._follow(log, count, timeout_s)

    async def credits(self) -> int | None:
        await self._ui.goto(HOME_URL)
        await self._ui.activate("button", ACCOUNT, exact=True)
        await self._ui.pause(1200)
        match = _CREDITS.search(await self._ui.text_of("body"))
        await self._ui.key("Escape")
        return int(match.group(1).replace(",", "")) if match else None

    async def _follow(self, log: ResponseLog, count: int, timeout_s: float) -> FlowOutcome:
        seen: dict[str, FlowMedia] = {}
        credits = None
        deadline = self._now() + timeout_s
        while self._now() < deadline:
            for method in MEDIA_METHODS:
                response = await log.next(method, timeout_s=self._poll_s)
                if response is None or response.status >= 400:
                    continue
                payload = decode_batch(response.text).get(method)
                if method == "jwpduf":
                    credits = credits_left(payload) if credits_left(payload) is not None \
                        else credits
                for media in media_records(method, payload):
                    old = seen.get(media.media_id)
                    seen[media.media_id] = _merge(old, media) if old else media
                    if media.status not in (None, _DONE, *_RUNNING):
                        raise ServerError(f"Flow could not make media {media.media_id} "
                                          f"(status {media.status})",
                                          hint="check the project in Flow; credits may be "
                                               "refunded")
            ready = [m for m in seen.values() if m.status == _DONE and (m.video_url or m.image_url)]
            if len(ready) >= count:
                return FlowOutcome(ready, credits, False)
        return FlowOutcome(list(seen.values()), credits, True)

    async def _checked_one(self, kind, values, name, *, aspect: bool):
        for value in values:
            nth = _group(kind, value if aspect else None)
            if await self._ui.checked(TUNE_ROLE, name(value), nth=nth):
                return value
        return None

    async def _close_tune(self) -> None:
        await self._ui.goto(self._ui.current_url())  # Escape does not close it; a reload does
        await self._ui.wait_for(PROMPT_EDITOR, timeout_s=30.0)


def _merge(old: FlowMedia, new: FlowMedia) -> FlowMedia:
    """Later responses fill in what earlier ones lacked (links arrive with as29s); a status
    never goes backwards, since a late "running" poll can follow the "done" record."""
    merged = {field: getattr(new, field) if getattr(new, field) is not None
              else getattr(old, field) for field in old.__dataclass_fields__}
    if old.status is not None and new.status is not None:
        merged["status"] = max(old.status, new.status)
    return FlowMedia(**merged)
```

**Files:**
- Create: `src/aistudio/_app/flow.py`
- Test: `tests/unit/test_app_flow.py`

**Interfaces:**
- Consumes: Tasks 1–5.
- Produces:
  - `flow_credits(profile, *, visible=False, browser=open_browser) -> dict`;
  - `flow_generate(profile, kind, prompt, *, model=None, aspect=None, count=None, duration=None, max_credits=None, project=None, out=None, overwrite=False, timeout_s=600.0, visible=False, browser=open_browser, downloader=download_signed, now=datetime.now, page_factory=FlowPage) -> dict`;
  - `STATE_FILE = "flow.json"` in `profile.root`, holding `{"project_id": …}`.

Rules (spec §3, §3.1, §3.2, §6, §7):
- **Before Chrome opens:**
  - the prompt is stripped and must not be empty;
  - `--max-credits` must be ≥ 0;
  - a `--project` must be a project id or a `flow.google.com/project/<id>` URL;
  - the `-m` model is resolved with `find_model`, then `check_options` runs;
  - output: when `count > 1`, `-o` must be omitted or an existing folder; when `count` is 1 or omitted, `-o` must not exist unless `--force`, and its folder must be writable.
- **Project:**
  - `--project` opens it.
  - Otherwise the stored id is opened. If it raises `NotFoundError`, a new "aistudio" project is created and stored.
  - With no stored id, a project is created and stored.
- **Defaults:**
  - `read_defaults(kind)` gives `previous`.
  - `wanted = Defaults(model.label if model else previous.model, aspect or previous.aspect, count or previous.count)`.
  - If `wanted != previous`, `apply_defaults` runs.
  - In `finally`, if they were changed, `apply_defaults(kind, previous)` runs. An `AIStudioError` there becomes a warning: `"could not restore Flow's {kind} defaults ({model}, {aspect}, x{count}); set them in Flow's settings"`.
- **Turn:**
  - `new_session()`, then `submit(instruction(...))`, then `wait_for_quote(90)`.
  - A quote of None raises `AgentReplyError(text[-500:], hint="rephrase the prompt or add options; nothing was spent")`.
- **Decide:** `Expect(kind, wanted.count, model.label if model else None, duration)`.
  - QUOTE_ONLY returns `{"status": "quoted", "credits", "count", "plan": text, "project", **warnings(mismatches)}`.
  - REJECT_MISMATCH: `reject()`, then `PlanMismatchError("; ".join(wrong), hint="nothing was spent; adjust the flags or the prompt")`.
  - REJECT_OVER_BUDGET: `reject()`, then `OverBudgetError(f"Flow quotes {credits} credits, over --max-credits {max}", hint=f"nothing was spent; re-run with --max-credits {credits} to accept")`.
  - APPROVE: `approve_and_follow(count=wanted.count, timeout_s)`.
- **Timeout:** returns `{"status": "timeout", "media_ids", "project_url", "credits_spent"}`.
- **Download:**
  - For each media, the link is `video_url` for video and `image_url` for image.
  - The extension comes from the downloaded bytes: `.mp4` for video, and for images `.png` if the data starts with `\x89PNG`, else `.jpg`.
  - The data is saved with `write_file`. On a single output with `-o`, the path is exactly `-o`. Otherwise it is `<folder>/flow-<kind>-<YYYYmmdd-HHMMSS>[-N]<ext>` via `free_name`.
  - Any `AIStudioError` from the downloader or the save is re-raised as the same type, with the hint `"Flow made media {ids} in {project_url}; download it there"`.
- **Two deliberate differences from the spec:**
  - spec §3.2's `session` is left out, because the page does not expose the chat session id;
  - `--project` takes a project id or link, and prefix/title matching comes with `flow projects` in plan B.
- **Done:** returns `{"status": "done", "files": [{"path", "mime_type", "bytes", "media_id"}], "credits_spent": quote.credits, "credits_left", "model": model.id if model else wanted.model, "project", **warnings}`.

```python
                      r"[0-9a-f]{12})/?$")


async def flow_credits(profile: Profile, *, visible: bool = False,
                       browser: Callable[..., Any] = open_browser,
                       page_factory: Callable[[Any], Any] = FlowPage) -> dict[str, Any]:
    async with browser(profile, window="visible" if visible else "minimized") as ui:
        credits = await page_factory(ui).credits()
    if credits is None:
        raise SchemaDriftError("Flow account menu", (), "a credits count")
    return {"credits": credits}


async def flow_generate(
    profile: Profile,
    kind: str,
    prompt: str,
    *,
    model: str | None = None,
    aspect: str | None = None,
    count: int | None = None,
    duration: int | None = None,
    max_credits: int | None = None,
    project: str | None = None,
    out: Path | None = None,
    overwrite: bool = False,
    timeout_s: float = 600.0,
    visible: bool = False,
    browser: Callable[..., Any] = open_browser,
    downloader: Callable[[str], Any] = download_signed,
    now: Callable[[], datetime] = datetime.now,
    page_factory: Callable[[Any], Any] = FlowPage,
) -> dict[str, Any]:
    prompt = prompt.strip()
    if not prompt:
        raise ValidationError(f"nothing to generate: the {kind} prompt is empty")
    if max_credits is not None and max_credits < 0:
        raise ValidationError("--max-credits must be 0 or more")
    project_id = _project_id(project) if project else None
    flow_model = find_model(model, kind) if model else None
    check_options(kind, flow_model, aspect, count, duration)
    _check_output(out, count or 1, overwrite)
    warnings: list[str] = []
    async with browser(profile, window="visible" if visible else "minimized") as ui:
        page = page_factory(ui)
        project_id = await _open(page, profile, project_id)
        previous = await page.read_defaults(kind)
        wanted = Defaults(flow_model.label if flow_model else previous.model,
                          aspect or previous.aspect, count or previous.count)
        try:
            if wanted != previous:
                await page.apply_defaults(kind, wanted)
            await page.new_session()
            await page.submit(instruction(kind, prompt, count=wanted.count,
                                          model_label=flow_model.label if flow_model else None,
                                          seconds=duration, aspect=aspect))
            turn = await page.wait_for_quote(timeout_s=90.0)
            if turn.quote is None:
                raise AgentReplyError(f"Flow's agent replied without a quote: {turn.text[-500:]}",
                                      hint="rephrase the prompt or add options; nothing was "
                                           "spent")
            expect = Expect(kind, wanted.count, flow_model.label if flow_model else None,
                            duration)
            decision, wrong = decide(turn.quote, parse_plan(turn.text), expect, max_credits)
            if decision is Decision.QUOTE_ONLY:
                return {"status": "quoted", "credits": turn.quote.credits,
                        "count": turn.quote.count, "plan": turn.text, "project": project_id,
                        **({"warnings": wrong} if wrong else {})}
            if decision is Decision.REJECT_MISMATCH:
                await page.reject()
                raise PlanMismatchError("; ".join(wrong),
                                        hint="nothing was spent; adjust the flags or the prompt")
            if decision is Decision.REJECT_OVER_BUDGET:
                await page.reject()
                raise OverBudgetError(f"Flow quotes {turn.quote.credits} credits, over "
                                      f"--max-credits {max_credits}",
                                      hint=f"nothing was spent; re-run with --max-credits "
                                           f"{turn.quote.credits} to accept")
            outcome = await page.approve_and_follow(count=wanted.count, timeout_s=timeout_s)
        finally:
            if wanted != previous:
                try:
                    await page.apply_defaults(kind, previous)
                except AIStudioError:
                    warnings.append(f"could not restore Flow's {kind} defaults "
                                    f"({previous.model}, {previous.aspect}, x{previous.count}); "
                                    "set them in Flow's settings")
    project_url = PROJECT_URL.format(id=project_id)
    if outcome.timed_out:
        return {"status": "timeout", "media_ids": [m.media_id for m in outcome.media],
                "project_url": project_url, "credits_spent": turn.quote.credits,
                **({"warnings": warnings} if warnings else {})}
    files = await _save_all(kind, outcome.media, out=out, overwrite=overwrite,
                            downloader=downloader, stamp=now(), project_url=project_url)
    return {"status": "done", "files": files, "credits_spent": turn.quote.credits,
            "credits_left": outcome.credits_left,
            "model": flow_model.id if flow_model else wanted.model, "project": project_id,
            **({"warnings": warnings} if warnings else {})}


def _project_id(value: str) -> str:
    match = _PROJECT.search(value.strip())
    if match is None:
        raise ValidationError(f"{value!r} is not a Flow project id or link",
                              hint="copy the id from https://flow.google.com/project/<id>")
    return match.group(1)


def _check_output(out: Path | None, count: int, overwrite: bool) -> None:
    if count > 1:
        if out is not None and not out.is_dir():
            raise ValidationError(f"{count} outputs need -o to be an existing folder",
                                  hint="leave out -o to save them in the current folder")
        check_folder(out or Path("."))
        return
    if out is not None and out.exists() and not overwrite:
        raise ValidationError(f"{out} already exists", hint="pass --force or choose another -o")
    check_folder(out.parent if out is not None and str(out.parent) else Path("."))


async def _open(page: Any, profile: Profile, project_id: str | None) -> str:
    if project_id is not None:
        await page.open_project(project_id)
        return project_id
    state = profile.root / STATE_FILE
    stored = (read_json(state) or {}).get("project_id") if state.exists() else None
    if stored:
        try:
            await page.open_project(stored)
            return stored
        except NotFoundError:
            pass  # deleted in Flow, or did not load: make a new one
    created = await page.create_project(DEFAULT_PROJECT_TITLE)
    profile.ensure()
    write_private_json(state, {"project_id": created})
    await page.open_project(created)
    return created


async def _save_all(kind: str, media: list[Any], *, out: Path | None, overwrite: bool,
                    downloader: Callable[[str], Any], stamp: datetime,
                    project_url: str) -> list[dict[str, Any]]:
    ids = ", ".join(m.media_id for m in media)
    folder = out if out is not None and out.is_dir() else Path(".")
    files = []
    try:
        for i, item in enumerate(media):
            url = item.video_url if kind == "video" else item.image_url
            if not url:
                raise SchemaDriftError("as29s", (), f"a {kind} link")
            data = await downloader(url)
            mime, ext = _type_of(kind, data)
            if out is not None and not out.is_dir() and len(media) == 1:
                path = out
            else:
                suffix = f"-{i + 1}" if len(media) > 1 else ""
                path = free_name(folder / f"flow-{kind}-{stamp:%Y%m%d-%H%M%S}{suffix}{ext}")
            saved = write_file(path, data, overwrite=overwrite and path == out)
            files.append({"path": str(saved), "mime_type": mime, "bytes": len(data),
                          "media_id": item.media_id})
    except AIStudioError as exc:
        note = f"Flow made media {ids} in {project_url}; download it there"
        exc.hint = f"{note} ({exc.hint})" if exc.hint else note
        raise
    return files


def _type_of(kind: str, data: bytes) -> tuple[str, str]:
    if kind == "video":
        return "video/mp4", ".mp4"
    if data.startswith(b"\x89PNG"):
        return "image/png", ".png"
    return "image/jpeg", ".jpg"
```

```python
"""``aistudio flow``: Google Flow video and image generation with a credit budget (spec §3)."""

from __future__ import annotations

import asyncio
from pathlib import Path
from typing import Any

import click

from aistudio._app.flow import flow_credits, flow_generate
from aistudio._flow.models import ASPECTS, MODELS
from aistudio.cli.error_handler import handle_errors
from aistudio.cli.inputs import read_text
from aistudio.cli.output import emit, json_option, stderr, stdout
from aistudio.cli.state import CliState


@click.group()
def flow() -> None:
    """Google Flow (flow.google.com): video and images, paid in Flow credits."""


@flow.command("credits")
@click.option("--visible", is_flag=True, help="Show the browser window instead of minimizing it.")
@json_option
@click.pass_obj
@handle_errors
def credits_cmd(state: CliState, visible: bool, json_output: bool) -> None:
    """How many Flow credits are left (reads the account menu; free)."""
    state.require_browser()
    result = asyncio.run(flow_credits(state.profile(), visible=visible))
    emit(result, json_output=json_output,
         render=lambda d: stdout.print(f"{d['credits']} Flow credits left", markup=False))


def _render(data: dict[str, Any]) -> None:
    if data["status"] == "quoted":
        stdout.print(f"Flow quotes {data['credits']} credits for {data['count']} output(s): "
                     f"{data['plan']}", markup=False)
        stdout.print(f"Nothing was spent. Re-run with --max-credits {data['credits']} to "
                     "generate.", markup=False)
    elif data["status"] == "timeout":
        stdout.print(f"Still running in Flow ({data['credits_spent']} credits spent): "
                     f"{data['project_url']}", markup=False)
    else:
        for file in data["files"]:
            stdout.print(f"Wrote {file['path']} ({file['bytes']} bytes)", markup=False)
        stdout.print(f"Spent {data['credits_spent']} credits; {data['credits_left']} left",
                     markup=False)
    for warning in data.get("warnings", []):
        stderr.print(f"Warning: {warning}", markup=False)


def _command(kind: str) -> click.Command:
    ids = [m.id for m in MODELS if m.kind == kind]

    @click.argument("prompt", required=False)
    @click.option("--prompt-file", type=click.Path(exists=True, dir_okay=False, path_type=Path),
                  help="Read the prompt from a file instead.")
    @click.option("-m", "--model", type=click.Choice(ids, case_sensitive=False),
                  help="Model (default: your Flow default).")
    @click.option("--aspect", type=click.Choice(list(ASPECTS[kind])))
    @click.option("--count", type=click.IntRange(1, 4), help="Outputs (default: your Flow "
                                                             "default).")
    @click.option("--max-credits", type=click.IntRange(0), help="Spend at most this many "
                  "credits; without it Flow's quote is shown and nothing is spent.")
    @click.option("--project", help="Flow project id or link (default: an 'aistudio' project).")
    @click.option("-o", "--out", type=click.Path(path_type=Path),
                  help="Output file, or a folder for several outputs.")
    @click.option("--force", is_flag=True, help="Overwrite the output file if it exists.")
    @click.option("--timeout", type=click.IntRange(30), default=600, show_default=True,
                  help="Seconds to wait for Flow to finish after approving.")
    @click.option("--visible", is_flag=True, help="Show the browser window.")
    @json_option
    @click.pass_obj
    @handle_errors
    def command(state: CliState, prompt: str | None, prompt_file: Path | None, json_output: bool,
                timeout: int, **options: Any) -> None:
        state.require_browser()
        content = read_text(prompt, prompt_file, arg="PROMPT", option="--prompt-file")
        if not json_output:
            window = "visible" if options["visible"] else "minimized"
            stderr.print(f"Asking Flow in a {window} Chrome window…", markup=False)
        out = options.pop("out")
        result = asyncio.run(flow_generate(
            state.profile(), kind, content, out=out, overwrite=options.pop("force"),
            timeout_s=float(timeout), **{**{"duration": None}, **options}))
        emit(result, json_output=json_output, render=_render)
        if result["status"] == "timeout":
            raise SystemExit(2)

    if kind == "video":
        command = click.option("--duration", type=int, help="Seconds (per the model: Veo "
                               "3.1 Lite/Fast 4/6/8, Quality 8, Omni 4/6/8/10).")(command)
    help_text = (f"Generate {kind}s with Google Flow. Without --max-credits it only shows "
                 "Flow's quote and spends nothing.")
    return flow.command(kind, help=help_text)(command)


video = _command("video")
image = _command("image")
```
